# 🇮🇳 Indian Retail Sales Analysis – Power BI

## 📊 Project Overview

This project presents an interactive Power BI dashboard designed to analyze Indian retail sales performance and identify important business trends and patterns.

The dashboard provides a consolidated view of sales performance across products, categories, regions, states, and payment modes.

---

## 🎯 Project Objective

The main objective of this project is to transform retail sales data into meaningful visual insights that can support business analysis and decision-making.

The dashboard helps analyze:

- Sales performance
- Order volume
- Product performance
- Category performance
- Regional performance
- State-level performance
- Payment mode distribution
- Monthly sales trends
- Return rate
- Average order value

## 📈 Dashboard Analysis

### Monthly Sales Analysis

Analyzed sales performance across different months to identify sales trends and patterns.

### Category Analysis

Compared sales performance across different product categories.

### Regional Analysis

Analyzed sales performance across different regions of India.

### State Analysis

Examined state-level sales performance to identify important market areas.

### Product Analysis

Analyzed product-level performance to understand which products contribute to sales.

### Payment Mode Analysis

Compared sales distribution across different payment methods.

---

## 🔍 Key Insights

- Electronics was identified as a dominant sales category.
- West and East regions showed strong sales performance.
- UPI represented a significant share of sales transactions.
- Sales were concentrated among leading states and products.
- Monthly analysis helped identify variations in sales performance.
